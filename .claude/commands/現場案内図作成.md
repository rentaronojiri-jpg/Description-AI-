# 現場案内図作成スキル

消防署に出す「現場案内図」（A4・1ページ・文字を直せるHTML＋PDF）を、住所を聞いて作る。

## 使い方

```
/現場案内図作成 <案件名>　<住所>
```
例：`/現場案内図作成 赤坂中村ビル　東京都港区赤坂3-13-13赤坂中村ビル8階`

## ひな形（これを写して作る）

`★現場ごと/★小岩　図面案件/案件/★赤坂中村ビル/消防書類/現場案内図_赤坂中村ビル_20261102.html`
（古い参考例：`★現場ごと/★ホウセイ建設/大宮店舗/消防書類/着工届/2現場案内図_大宮店舗_20260811.html`）

構成は上から ①タイトル「現場案内図」 ②表（工事名称・施行者・作成日） ③郵便番号＋住所の枠 ④地図（赤いピン）＋注記 ⑤周辺情報（最寄駅・立地・建物）。
ひな形は文字を直接直せて、上部の「💾 上書き保存」ボタン付き。この仕組みは変えない。

## 手順

1. **工事名称を決める**：案件フォルダの見積書・工程表の題名から取る（例：「赤坂中村ビル8階 オフィス改修工事」）。名前が分からなければ本人に聞く。
2. **郵便番号**を確認して入れる（住所から調べる。推測で入れない）。
3. **地図（Googleマップ）**
   - Chromeの操作ツールで `https://www.google.com/maps/search/<住所>+<ビル名>` を開く。ページの題名が入力した住所と一致するか確認する。
   - 開いたページのURLにある `!3d緯度!4d経度` を控え、`https://www.google.com/maps/place/<緯度>,<経度>/@<緯度>,<経度>,18z` を開く。左の枠は左端の「<」で閉じ、赤いピンが見える状態でスクリーンショット（保存あり）を撮る。
   - Pythonの PIL で、ピンが中央付近に来て、最寄駅の名前が入る範囲を切り出す（例：880×560）。マウスの矢印が映ったら周りの地図で塗りつぶして消す。
   - 切り出した画像をbase64にして、ひな形の地図の `<img>` に入れ替える。ブラウザ操作で開いたタブは最後に閉じる。
   - 自動で出力する方法では地図が表示されない（空白になる）ので、必ずこの画像方式にする。
4. **周辺情報**：最寄駅・距離・徒歩分数は概算であることを本人に伝える（地図の縮尺で確認する）。
5. **表の項目**：「提出先」と「代表取締役」は書かない（本人の指示）。施行者は「株式会社AXIS」のみ。作成日は今日の日付。
6. **保存**：案件フォルダの `消防書類/` に `現場案内図_<案件名>_<yyyymmdd>.html` と同名の `.pdf`。
7. **PDF**：Chromeの印刷機能で作る。Windowsのパスは `([System.Uri]$path).AbsoluteUri` でURLにする。
   `chrome.exe --headless --disable-gpu --no-pdf-header-footer --print-to-pdf=<出力先> <HTMLのURL>`
8. **確認**：PDFを開いて、1ページに収まっているか・地図とピンの位置・住所・工事名称・旧案件の文言の残りがないかを見る。別のエージェントでも検査してから渡す（`CLAUDE.md` の決まり）。

## 本人への報告

- 保存先のフルパス（HTMLとPDF）
- 直し方：HTMLをChromeで開いて文字をクリックして直し「上書き保存」。PDFにするときは印刷から「PDFに保存」。
- 提出前に見てほしい点（地図のピンの位置、駅までの距離は概算）
