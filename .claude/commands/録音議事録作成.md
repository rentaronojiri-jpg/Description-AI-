# 録音議事録作成スキル

録音データの自動文字起こしテキストを読み込み、整形された議事録HTML（印刷・PDF変換対応）を生成するスキル。

## 使い方

```
/録音議事録作成
```

実行後、Claude が以下の手順で議事録を自動生成する。

---

## 実行手順

### 1. テキストファイルを読み込む

`録音議事録/` フォルダ内の `.txt` ファイルを読み込む。  
複数ある場合はユーザーにどのファイルを対象にするか確認する。

### 2. テキストを解析・整理する

音声認識の誤変換・口語表現を補正しながら、以下を抽出する：

- **日時・場所**：テキストや会話の文脈から推定（不明な場合は今日の日付を使用）
- **出席者**：名前・肩書きが読み取れる範囲で抽出
- **協議内容**：トピックごとに分類してまとめる
- **決定事項**：決まったこと・合意事項を箇条書きで整理
- **懸案事項・確認事項**：未解決の問題・要確認項目
- **次回アクション**：誰が何をするかを整理（担当者不明の場合は「要調整」）

### 3. HTMLファイルを生成する

**必ず `録音議事録/議事録テンプレート.html` をコピーして生成する**（デザイン・AXISロゴ・編集/保存機能がすべて入ったデフォルト雛形。`<style>`・ツールバー・`<script>`・ロゴ画像は変更しない）。`{{...}}` のプレースホルダーと `<div id="docContent">` 内のサンプル行を、解析した内容に置き換える。該当しないセクションは削除、項目が多い場合は `<h3>`・`<li>`・表の行を増やす。`<title>` も会議日に置き換える。

雛形の仕様：

- **デザイン**：紺（#0f2a43）＋ロゴのオレンジ（#e8641b）配色。冒頭に AXIS ロゴ（HTMLに埋め込み済み・透過版）、見出しは紺グラデ帯、表は紺見出し、確認事項は黄ハイライト。文字は黒で濃く、薄い文字色は使わない
- **レイアウト**：A4印刷対応、ブラウザで印刷→PDF保存を前提
- **メタ情報テーブル**：日付・作成者・出席者・備考を冒頭に配置
- **本文編集**：本文（ツールバー以外）は `contenteditable="true"` にし、ブラウザ上で直接書き換えられるようにする
- **保存機能**：File System Access API（`showSaveFilePicker` 等）を使ったツールバーを冒頭に設置し、「上書き保存」「名前を付けて保存」ボタンで編集内容をそのままHTMLファイルへ保存できるようにする（非対応ブラウザではダウンロードにフォールバック）。印刷時はツールバーを非表示にする

**出力先**：`録音議事録/`  
**ファイル名**：`議事録_YYYYMMDD.html`（日付は会議日、不明な場合は今日の日付）

### 4. 完成を報告する

生成したファイルのパスを伝え、以下を案内する：

- ブラウザで開くと本文を直接クリックして編集できること
- 編集後は冒頭のツールバーの「上書き保存」「名前を付けて保存」でHTMLファイルとして保存できること（初回保存時はブラウザの保存先ダイアログでファイルを選択）
- ブラウザで開いて **Ctrl+P → PDFに保存** でPDF化できること
- 内容に誤りや追記がある場合はチャットで伝えてもらえばすぐ対応できること

## 議事録の構成テンプレート

| セクション | 内容 |
|---|---|
| メタ情報 | 日付・作成者・出席者・備考 |
| 建物/現場の概要 | 構造・フロア・工事対象範囲（該当する場合） |
| 協議内容 | トピックごとに見出しで分類 |
| 決定事項 | 番号付きテーブルで整理 |
| 確認事項・懸案事項 | ハイライト付きで強調 |
| 次回アクション | チェックボックス形式のリスト |
| 注記 | 音声認識に関する免責事項を末尾に記載 |

---

## 出力ルール

- 音声認識の誤変換は文脈から補正して読みやすくする
- 読み取れなかった箇所は「（不明）」と記載してユーザーが後で確認できるようにする
- 固有名詞（人名・会社名・地名）は確認が取れたもののみ記載する
- 作成者のデフォルトは「野尻 連太朗（株式会社AXIS）」
