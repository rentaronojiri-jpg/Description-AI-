# 請求書まとめスキル

`請求書まとめ/<◯月締め>/` フォルダ内の業者請求書PDFをすべて読み込み、
会社ごとの支払金額が一目でわかる「支払管理表」Excel（.xlsx）を自動生成するスキル。
支払状況（未払い／問題あり／支払い済み）をドロップダウンで選択でき、選択に応じて行が自動で色分けされる。

## 使い方

```
/請求書まとめ
```

対象月を指定してもよい（例：`/請求書まとめ 7月締め`）。指定がなければ `請求書まとめ/` 配下で最も新しい「◯月締め」フォルダを対象にする。

---

## 実行手順

### 1. 対象フォルダとPDFを確認する

`請求書まとめ/<◯月締め>/` 配下の `.pdf` をすべて列挙して読み込む（Read ツールでそのまま読める。ファイル名が日本語でも問題ない）。

### 2. 各PDFから情報を抽出する

| 項目 | 抽出元の目安 |
|---|---|
| 会社名・氏名 | 発行元（右上または署名欄）。個人名の請求書もある |
| 工事内容・件名 | 「工事名」「件名」「現場名」欄。複数現場が1枚にまとまっている場合はまとめて記載 |
| 請求書番号 | 「請求書番号」「No.」欄（無ければ空欄） |
| 請求日 | 発行日 |
| ご請求金額（税込） | 合計・ご請求金額欄（消費税込みの最終金額） |

**同一会社で複数枚の請求書がある場合は行を分けて記載する**（合算しない。会社ごとの合計は集計シート側でSUMIFにより自動計算する）。

### 3. Excelを生成する（openpyxl）

出力先: `請求書まとめ/<◯月締め>/支払管理表_<◯月締め>.xlsx`

**シート1「請求一覧」**（列: No / 会社名・氏名 / 工事内容・件名 / 請求書番号 / 請求日 / ご請求金額（税込） / 支払状況 / 備考）

- ヘッダー行は濃紺背景＋白太字、罫線あり、オートフィルター、先頭行固定
- 金額列は `#,##0"円"` 形式
- 「支払状況」列（G列）に **未払い／問題あり／支払い済み** のデータ入力規則（ドロップダウン）を設定。データ行だけでなく将来の追加分用に余白行（10〜15行程度）にも適用する
- 条件付き書式（FormulaRule）で行全体を色分け：未払い＝薄黄色（`FFF2CC`）／問題あり＝薄赤（`F8CBAD`）／支払い済み＝薄緑（`C6E0B4`）
- 全社合計を `=SUM(...)` で最終行に表示
- 右側の空き列に支払状況別（未払い／問題あり／支払い済み）の件数・金額をCOUNTIF/SUMIFで自動集計するミニサマリーを配置

**シート2「会社別集計」**（列: 会社名・氏名 / 請求件数 / ご請求金額合計（税込） / 未払い件数 / 支払い済み件数）

- 「請求一覧」シートをCOUNTIF・SUMIF・COUNTIFSで参照する数式にする（一覧シートの支払状況を変更すれば自動で反映される）
- 金額の大きい順に並べる
- 最終行に全社合計を表示

初期値として全行の「支払状況」は「未払い」にしておく。

参考実装は過去のセッションで `株式会社AXIS` の7月締め分に対して作成済み（列構成: No, 会社名・氏名, 工事内容・件名, 請求書番号, 請求日, ご請求金額（税込）, 支払状況, 備考 の8列。支払期限・元ファイル列は不要と指示されたため含めない）。

### 4. ユーザーに送付・報告する

- SendUserFile で生成したExcelを送付する
- 会社ごとの合計金額を一覧で本文にも記載する
- 同一会社で複数請求書があった場合はその旨を明記する
