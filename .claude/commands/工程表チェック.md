# 工程表チェックスキル

Excel/CSV形式の工程表を4つのAIエージェントが異なる視点で並列チェックし、一切の漏れがない総合レポートを出力するスキル。

## 使い方

```
/工程表チェック <ファイルパス>
```

例：
```
/工程表チェック 工程表チェック/2026_○○邸リノベ工程表.xlsx
```

---

## 実行手順

### 1. ファイルを読み込む

まず、指定されたExcel/CSVファイルのパスを確認する。パスが指定されていない場合はユーザーに尋ねる。

#### Excelの場合（.xlsx / .xls）

```powershell
python -c "import openpyxl; print('ok')" 2>&1
# エラーなら：
python -m pip install openpyxl
```

```powershell
python -c "
import sys, io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8', errors='replace')
import openpyxl
wb = openpyxl.load_workbook(r'<ファイルパス>', data_only=True)
for sheet_name in wb.sheetnames:
    ws = wb[sheet_name]
    print(f'=== シート: {sheet_name} ===')
    for row in ws.iter_rows(values_only=True):
        row_data = [str(c) if c is not None else '' for c in row]
        if any(c.strip() for c in row_data):
            print('\t'.join(row_data))
" 2>&1 | Out-String
```

#### CSVの場合（.csv）

```powershell
python -c "
import sys, io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8', errors='replace')
import csv
with open(r'<ファイルパス>', encoding='utf-8-sig') as f:
    for row in csv.reader(f):
        print('\t'.join(row))
" 2>&1 | Out-String
```

読み込んだ内容をテキストとして保持し、以降の各エージェントに渡す。

---

### 2. 工事の基本情報を把握する

読み込んだ工程表から以下を確認・メモする：

- 工事名・現場名
- 工事種別（新築・リノベーション・外壁・内装・設備など）
- 工期（着工日〜竣工日）
- 記載されている工種一覧

---

### 3. 4つのエージェントで並列チェックを実施する

以下の4エージェントを **同時に** 起動し、それぞれの専門視点で工程表をチェックする。

#### エージェント1：工程網羅チェッカー
**役割:** 工事種別に必要な工程が全て含まれているかを確認する

確認項目：
- 工事種別（新築・リノベ・外壁工事など）に応じた標準工程が揃っているか
  - **新築の標準工程:** 仮設→地盤調査→基礎→土台・躯体→上棟→屋根→外壁→サッシ→断熱→電気粗配線→設備粗配管→内装（ボード・クロス・床）→建具→外構→竣工検査→引き渡し
  - **リノベーションの標準工程:** 仮設→解体→下地補修→電気・設備更新→断熱改修→内装→設備機器設置→外装（必要に応じ）→竣工検査→引き渡し
  - **外壁工事の標準工程:** 仮設足場→既存外壁確認→下地補修→シーリング→塗装/張替→足場解体→検査
- 「養生」「清掃」「竣工検査」「引き渡し」など最終工程が含まれているか
- 工程の着手順序が建築工法として正しいか（例：基礎が完了する前に躯体工事が始まっていないか）
- 専門工事（電気・給排水・ガス・空調）が含まれているか

出力形式：
```
【工程網羅チェック結果】
工事種別：○○
標準工程との比較：
  ✅ 含まれている工程：...
  ⚠️ 抜けている可能性がある工程：...（理由：...）
  ❌ 明確に不足している工程：...
推奨追加工程：...
```

#### エージェント2：日程整合性チェッカー
**役割:** 日程の矛盾・非現実的なスケジュールを検出する

確認項目：
- **工期の妥当性:** 各工程の作業日数が現実的か（例：クロス工事1日は工区によっては非現実的）
- **先行・後続関係の矛盾:** 先行工事が完了する前に後続工事が開始されていないか
  - 基礎→躯体、躯体→屋根、粗配線→ボード、ボード→クロス の順序を必ず確認
- **並行作業の妥当性:** 同時進行できない工程が重なっていないか
- **余裕日数:** 工程間に検査・養生・乾燥待ちの期間が確保されているか
  - コンクリート養生：最低7日（通常28日）
  - 下地乾燥（パテ・モルタル等）：最低1〜2日
- **天候・季節リスク:** 梅雨・冬期の外部工事にリスクフラグ
- **年末年始・盆・祝日:** 業者休業期間が工程に影響しないか
- **全体工期の整合:** 着工日〜竣工日の合計日数と、各工程の積算日数が一致するか

出力形式：
```
【日程整合性チェック結果】
全体工期：○年○月○日〜○年○月○日（○日間）
問題のある箇所：
  ⚠️ [工程名] ○月○日〜：前工程（○○）の完了前に開始している
  ⚠️ [工程名] ○月○日〜：作業日数○日は○○の規模で短すぎる可能性
  ❌ [工程名] ：養生・乾燥期間が確保されていない
季節リスク：...
休日・連休の影響：...
```

#### エージェント3：申請・法規チェッカー
**役割:** 各種申請・届出・検査のタイミングが工程表に組み込まれているかを確認する

確認項目：
- **建築確認申請:** 工事着工前に取得完了しているか（審査期間：木造2週間〜、RC1ヶ月〜）
- **確認済証受領:** 着工前に完了しているか
- **中間検査:** 工事中の法定検査（地域・構造により義務付け）が工程表に含まれているか
- **完了検査:** 竣工後・引き渡し前に予定されているか
- **道路占用・使用許可:** 足場設置や搬入作業で道路を使う場合の申請期間（申請〜許可：2〜4週間）
- **足場設置届:** 10m以上の足場は労基署への届出が必要（設置30日前まで）
- **産業廃棄物マニフェスト:** 解体工事を含む場合は廃棄物処理の記録
- **ガス・電気・水道の供給停止・切り替え工程:** 必要な場合に含まれているか

出力形式：
```
【申請・法規チェック結果】
確認された申請・届出：
  ✅ ...
不足している可能性のある申請・届出：
  ⚠️ [申請名]：理由...（必要な場合、申請期間○日前には開始が必要）
  ❌ [申請名]：明確に抜けている
法規上の注意点：...
```

#### エージェント4：調達・リソースチェッカー
**役割:** 資材発注・業者手配のタイミングが適切かを確認する

確認項目：
- **資材の発注リードタイム:** 工事開始前に資材が現場に到着できるか
  - 一般建材：1〜2週間
  - 特注品・輸入品：4〜12週間
  - 木材（プレカット）：2〜3週間
  - ユニットバス・キッチン等の設備機器：4〜6週間
  - サッシ（特注）：4〜8週間
- **専門業者の手配順序:** 電気・設備・大工・左官・塗装・内装などの職種が適切な順序で手配されているか
- **重複による作業不効率:** 同じ日・同じ場所で複数の職種が密集していないか
- **足場の活用効率:** 足場がある期間に、足場を必要とする全ての作業（外壁・屋根・塗装・サッシ等）が集中して行われているか
- **廃材・残材の処理:** 解体・撤去工事後の廃材処理日程が含まれているか
- **現場監督の立会い必要日程:** 検査・立会いが必要な工程で人員が割り当てられているか

出力形式：
```
【調達・リソースチェック結果】
資材発注タイミングの問題：
  ⚠️ [資材名]：工事開始○日前の発注では間に合わない可能性（リードタイム○日）
  ❌ [資材名]：発注タイミングの記載がなく、手配遅延リスクがある
業者手配の問題：
  ⚠️ ...
足場活用：...
```

---

### 4. 総合レポートを作成する

4エージェントの結果を統合し、以下の形式でユーザーに報告する：

---

```
## 工程表 総合チェックレポート
工事名：○○　／　チェック日：YYYY年MM月DD日

### サマリー
| チェック項目 | 問題件数 | 重大度 |
|---|---|---|
| 工程網羅 | ○件 | 高/中/低 |
| 日程整合性 | ○件 | 高/中/低 |
| 申請・法規 | ○件 | 高/中/低 |
| 調達・リソース | ○件 | 高/中/低 |

**総合評価：** ✅ 問題なし / ⚠️ 要確認あり / ❌ 修正必須

---

### 詳細チェック結果

#### 1. 工程網羅チェック
（エージェント1の結果をそのまま記載）

#### 2. 日程整合性チェック
（エージェント2の結果をそのまま記載）

#### 3. 申請・法規チェック
（エージェント3の結果をそのまま記載）

#### 4. 調達・リソースチェック
（エージェント4の結果をそのまま記載）

---

### 優先対応事項（重大度：高のみ）
1. ...
2. ...

### 推奨修正内容
（工程表をどう修正すべきかを具体的に記述）
```

---

### 5. 完了を伝える

- チェックファイル名・工事名
- 発見された問題の総数と重大度の内訳
- 次のアクション案（工程表の修正依頼・再チェックなど）
