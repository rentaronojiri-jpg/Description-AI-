# 株予測ツール起動スキル

`株予測ツール/` のWeb版（オンライン専用・常時ライブ取得・テクニカル×ファンダメンタルズ×世界情勢の3専門エージェントによるチーム評価）を起動するスキル。

## 使い方

```
/株予測ツール起動
```

---

## 実行手順

### 1. 既に起動しているか確認する

```
curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8765/ --max-time 3
```

`200` が返れば起動済み。サーバーは起動せず、手順4（ブラウザを開く）だけ行う。

### 2. 起動していなければサーバーをバックグラウンドで起動する

`株予測ツール` フォルダに移動して起動する。**パス区切りは forward slash（`webapp/server.py`）を使うこと**。
backslash（`webapp\server.py`）だとBashツール上でエスケープされてパスが壊れる。

```
cd "株予測ツール" && py webapp/server.py
```

`run_in_background: true` で実行する（フォアグラウンドで実行すると待ちっぱなしになる）。

### 3. 起動完了を待つ

ポート8765への接続確認を数秒おきにポーリングする（最大20秒程度）。

```
for i in $(seq 1 20); do
  code=$(curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8765/ 2>/dev/null)
  if [ "$code" = "200" ]; then echo "server up"; break; fi
  sleep 1
done
```

### 4. ブラウザで開く

```
start http://127.0.0.1:8765/
```

### 5. 完了報告

「新規起動した」か「既に起動していたので開き直した」かを一言で伝える。

---

## 補足

- サーバーはPython Flaskの開発用サーバー。ウィンドウを閉じる／プロセスを止めるまで動き続ける。
- ダブルクリックで起動したい場合は `株予測ツール\株予測ツールWeb版を起動.bat` でも同じ動作になる。
- データ取得は常にyfinanceからのライブ取得（キャッシュなし）。ブラウザで分析するたびに最新データを取りに行くオンライン専用ツール。
