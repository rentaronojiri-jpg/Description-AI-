# 書類チェックスキル

`書類チェック/` フォルダ内のPDFをすべて読み込み、内容を確認・要約してチェックポイントを報告するスキル。

## 使い方

```
/書類チェック
```

---

## 実行手順

### 1. PDFを収集する

`書類チェック/` フォルダ内のPDFを列挙する。OneDriveのクラウドファイルは通常の `Get-ChildItem` では取得できないため、必ず `-Force` フラグを使う：

```powershell
Get-ChildItem -LiteralPath "書類チェック" -Recurse -Force -Filter "*.pdf" | Select-Object Name, FullName
```

### 2. PDFテキストを抽出する

pymupdf（fitz）を使ってテキストを抽出する。初回は未インストールの場合があるため、インストール確認から始める：

```powershell
python -c "import fitz; print('ok')" 2>&1
# エラーなら：
python -m pip install pymupdf
```

テキスト抽出（文字化け防止のため stdout を UTF-8 に指定）：

```powershell
python -c "
import sys, io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8', errors='replace')
import fitz
doc = fitz.open(r'{ファイルパス}')
print(f'ページ数: {len(doc)}')
for i, page in enumerate(doc):
    print(f'--- ページ {i+1} ---')
    print(page.get_text())
" 2>&1 | Out-String
```

### 3. 書類の種類を判定してチェック項目を選ぶ

読み込んだ内容からどの種類の書類かを判定し、対応する確認ポイントを使う：

| 書類の種類 | 確認ポイント |
|---|---|
| 工事契約書 | 当事者名・工事名・工事場所・着工日・完了日・請負金額・支払条件・違約金・瑕疵担保期間・署名日付の記入漏れ |
| 見積書 | 発行者・発行日・有効期限・工事種別・金額（税抜・税込）・単価の妥当性 |
| 発注書 | 発注者・受注者・発注金額・工期・工事内容の明確さ |
| 請求書 | 請求先・請求日・支払期限・請求金額（税抜・税込）・振込先 |
| 保証書 | 対象範囲・保証期間・免責事項 |
| その他 | タイトル・日付・当事者・金額・署名欄の有無を汎用的に確認 |

### 4. チェック結果を報告する

以下の形式でまとめてユーザーに報告する：

---

**チェックレポートの構成：**

```
## 「{ファイル名}」の内容確認レポート
（ページ数、書類種別）

### 基本情報
（表形式：当事者・日付・金額・工事情報など）

### 支払条件・金額（該当する場合）
（表形式：タイミング・金額・期限）

### 主な条項・内容の要点
（箇条書き：重要条項をわかりやすく要約）

### 気になる点・確認推奨事項
（番号付きリスト：空欄・不備・注意点を具体的に指摘）
```

---

複数ファイルがある場合は、ファイルごとに同じ形式で続けて報告する。

### 5. 完了を伝える

- チェックしたファイル数・ファイル名
- 対応が必要な項目があればその数と概要
- 次のアクション案（記入漏れの補記依頼・差し戻し・保管など）
