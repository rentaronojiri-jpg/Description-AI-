# 案件工期グラフスキル

`★案件一覧工程/` にある工程表（Excel・PDF）を全部読み、案件ごとの工期を一目で比べられる横棒グラフ（A3横・画面上で直せるHTML）を作る。

## 使い方
```
/案件工期グラフ
```
「案件の工期を横棒グラフにして」「案件一覧を最新にして」などでも使う。使い手は事務担当なので、専門用語を使わず自分で進める。

## 手順

### 1. 工程表をすべて読む
`★案件一覧工程/` の中の `.xlsx` と `.pdf` を全部読む（`案件別工期_横棒グラフ_*.html` は出力なので読み込まない）。
- **Excel**: 棒は「図形」なので、セルの値だけでは分からない。`xl/drawings/drawingN.xml` の図形の位置（開始列〜終了列）を、2行目の日付の列に当てはめて日付にする。シート名と表題（A1）が食い違うことがある（例: シート「武蔵村山ジムスタ」の表題は「上尾西塚様店舗改修工事」）→ 表題の名前を使い、報告で一言伝える。使い回しの残骸（別案件の「引き渡し」目印、空シート、地図だけのシート）は無視する。Excelをそのまま画像で見たいときは PowerShell の Excel COM で PDF 化する（読み取り専用で開く）。
- **PDF**: Pythonは必ず `python -I -X utf8`（文字化け防止）。PyMuPDFで文字を抜き、文字が出ないPDFは画像化して目視する。工期・着工日・竣工日・引渡日は表紙の欄か最初のページ上部にある。
- 同じ案件がExcelとPDFの両方にあるときは1件にまとめ、日付が食い違えば新しいほうを使い報告する。
- 日付は推測しない。読み取れない・食い違う所は、報告で本人に確認する。

### 2. 案件ごとに次を整理する
案件名 / 着工日（工事の開始）/ 終了日 / 引渡し日（あれば）/ 準備期間（見積・申請・工事準備などの着工前。あれば）/ 出典。

### 3. HTMLを作る
ひな形 `★案件一覧工程/案件別工期_横棒グラフ_ひな形.html` をコピーし、スクリプト冒頭の `PROJECTS` 配列・`TODAY`・作成日表示・下部の「ご確認ください」の注記だけを今回の内容に差し替える。デザインや編集パネルは変えない。
- 保存先: `★案件一覧工程/案件別工期_横棒グラフ_<今日のYYYYMMDD>.html`（古いものは残す）
- 色: 完了=灰／施工中=橙／これから=青。今日の赤ラインは出さない（本人の指示）。
- 並びは着工日の早い順。印刷はA3横1ページ、編集パネルは印刷されない。

### 4. 確認用エージェントで検査する（必須）
本人に渡す前に、別のエージェントで元の工程表と照合する。案件の抜け、着工日・終了日・引渡日・準備期間の一致、表示崩れ（Edgeのヘッドレスでスクリーンショット: `"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless --screenshot=...`）を見る。指摘があれば直してから報告する。

### 5. 報告
- 保存先のフルパス
- 案件ごとの工期の表
- 確認してほしい点（シート名と表題の食い違い、仮の工程表、引渡し日が無い案件など）
- 検査結果（問題なし／直した点）を一言
