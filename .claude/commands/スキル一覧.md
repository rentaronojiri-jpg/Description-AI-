# スキル一覧

このプロジェクト（AI事務）で使えるスラッシュコマンド（カスタムスキル）の一覧。

> **使い方**: チャット欄に `/スキル名` と入力して実行する。

---

## カスタムスキル（プロジェクト固有）

| コマンド | 概要 | 主な用途 |
|----------|------|----------|
| `/秘書` | 案件全体の進捗把握・スケジュール調整・資料の所在案内・雑務相談を担当する総合秘書エージェント | 何を手伝ってほしいか決まっていないとき・全体の状況を確認したいとき |
| `/見積書作成` | 現場写真から工事内容を読み取り、見積書HTMLを自動生成 | 新しい見積書を作りたいとき |
| `/見積もり10UP` | 既存の見積書HTMLを、㎡項目は単価据え置き・数量調整で約10%増額した新ファイルとして出力（元データは残す） | 見積金額を調整したいとき |
| `/業者一覧作成` | `業者見積もり/` のPDFをすべて読み込み、業者連絡先一覧表（HTML）を生成・更新 | 業者が増えたとき・一覧を最新化したいとき |
| `/予算管理PDF読み込み` | `業者見積もり/` のPDFをすべて読み込み、予算管理テンプレートの業者支払管理欄を自動記入 | 業者見積が揃ったとき・予算管理表を更新したいとき |
| `/請求書まとめ` | `請求書まとめ/◯月締め/` の請求書PDFをすべて読み込み、会社ごとの支払金額と支払状況（未払い/問題あり/支払い済み）を管理できるExcelを自動生成 | 月締めの請求書が揃ったとき・支払管理表を作りたいとき |
| `/エクセル修正スキル` | openpyxl で生成した Excel の罫線・文字切れを修正 | 見積書テンプレートの罫線が途切れる・文字が切れるときに実行 |
| `/書類チェック` | `書類チェック/` のPDFをすべて読み込み、内容・記入漏れ・不備を確認してレポートを出力 | 契約書・見積書・請求書などを受け取ったときに確認したいとき |
| `/工程表作成` | 案件フォルダの見積・図面・現場写真をすべて読み込み、お客様提出用の工程表（A3横・ドラッグ等で編集できるHTML＋PDF）を、資料読み込み／工程案作成／4視点チェックの複数エージェントで分担して作成 | 新しい案件の工程表を作りたいとき（着工日・期間を指定） |
| `/案件工期グラフ` | `★案件一覧工程/` の工程表（Excel・PDF）をすべて読み、案件ごとの工期を横棒グラフ（A3横・画面上で日付を直せるHTML）にまとめる | 案件の工期を一覧で比べたいとき・工程表が増えたとき |
| `/工程表チェック` | Excel/CSV工程表を4つのAIエージェントが並列チェックし、漏れ・矛盾・法規不備・調達リスクを総合レポートで出力 | 工程表を作成・受け取ったときに一切の抜けなく確認したいとき |
| `/録音議事録作成` | 録音の自動文字起こしテキストを読み込み、議事録HTML（印刷・PDF対応）を自動生成 | 打ち合わせの録音を議事録にしたいとき |
| `/現場案内図作成` | 案件名と住所から、消防提出用の現場案内図（A4・Googleマップの地図付き・文字を直せるHTML＋PDF）を作る | 消防署に着工届などを出すとき |
| `/株予測ツール起動` | 株予測ツールWeb版（オンライン専用・3専門エージェントのチーム評価）をローカルサーバーで起動しブラウザで開く | 株予測ツールを使いたいとき |
| `/再接続` | 「再接続して」と言うと `claude --continue` を新しいウィンドウで起動し、直前の会話を引き継いで再開する | 接続が切れた・会話の続きから始めたいとき |
| `/スキル一覧` | このファイルを表示する | 使えるスキルを確認したいとき |

---

## システム標準スキル（Claude Code 組み込み）

| コマンド | 概要 |
|----------|------|
| `/code-review` | コードのバグ・改善点をレビュー（`ultra` オプションで深い多段階レビュー） |
| `/verify` | 変更が正しく動作するかアプリを実際に動かして確認 |
| `/simplify` | コードの整理・簡略化（バグ修正ではなく品質向上） |
| `/security-review` | セキュリティ観点でブランチの変更をレビュー |
| `/run` | プロジェクトのアプリを起動して動作確認 |
| `/init` | CLAUDE.md（コードベースのドキュメント）を初期生成 |
| `/schedule` | 定期実行するクラウドエージェントを作成・管理 |

---

## スキルの追加方法

`.claude/commands/` フォルダに `スキル名.md` を作成するだけで自動的にコマンドとして登録される。

```
AI事務/
└── .claude/
    └── commands/
        ├── エクセル修正スキル.md   ← /エクセル修正スキル
        ├── 請求書まとめ.md         ← /請求書まとめ
        ├── 工程表作成.md           ← /工程表作成
        ├── 案件工期グラフ.md       ← /案件工期グラフ
        └── スキル一覧.md           ← /スキル一覧
```
