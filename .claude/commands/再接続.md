# 再接続スキル

「再接続して」と言われたら、直前の会話を引き継いで Claude を立ち上げ直す（`claude --continue` を実行する）スキル。

## 使い方

```
/再接続
```

または「再接続して」と話しかける。

---

## 実行手順

### 1. 新しい端末ウィンドウで `claude --continue` を起動する

今の会話の中で直接実行すると待ちっぱなしになるため、別ウィンドウで起動する。
作業フォルダは AI事務 フォルダにする。

```
Start-Process powershell -ArgumentList '-NoExit','-Command','Set-Location "C:\Users\renta\OneDrive\Desktop\AI事務"; claude --continue'
```

（PowerShellツールで実行する）

### 2. 完了報告

次の一言だけ伝える。

「新しい黒い画面（ウィンドウ）で前回の続きを開きました。そちらで続けてください。」

---

## 補足

- `claude --continue` は、このフォルダで直前に行った会話をそのまま引き継いで再開するコマンド。
- 起動に失敗したら（`claude` が見つからないなど）、エラー内容を平易な言葉で伝える。
