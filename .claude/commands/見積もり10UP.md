# 見積もり10UPスキル

既存の見積書HTML（`見積書テンプレート_単価編集用.html` 形式）を、見た人に高いと思わせずに約10%増額した新しい見積書として出力するスキル。元ファイルは必ず残す。

## 使い方

```
/見積もり10UP
```
対象ファイルのパス（または案件名）と、必要なら増額率（デフォルト10%）を伝える。

## 調整ルール（ユーザー指定・必ず守る）

- ㎡が出ている工事は **単価を上げず、数量で調整**する
- **数量が少ない項目はいじらない**（㎡で30未満、式・箇所・台・本などの項目、建具・衛生機器など）
- 見た人が高いと思わない見え方にする：数量は整数に丸める。同じ面積を使う項目（足場・防音パネル・仮設材運搬、外壁の下地処理と塗装など）は同じ数量に揃える
- 現場管理費・諸経費・法定福利費など直接工事費の％連動項目は、同率で増額する
- **元データは残し、新しいファイルで出す**（`◯◯_10%増.html` として同じフォルダに保存）

## 手順

1. 対象HTMLを特定する（案件フォルダの `見積り/提出/` など）。複数候補があればユーザーに確認
2. スクリプトを実行する
   ```
   python 見積もり作成/見積もり増額/make_uplift.py "<元.html>" "<元>_10%増.html" 1.10
   ```
   - 第3引数は倍率（10%増=1.10）。出力の `tuned` 行で実際の増額率を確認
   - 数量が決まる仕組み：対象項目に共通の係数を掛けて整数に丸め、残差を単価の高い項目の数量±で微調整し、目標に合わせる
   - ％連動項目の名称は `PCT`、単位が「式」でも面積扱いの項目は `AREA_NAMES` に定義。案件で名称が違う場合はスクリプト冒頭を調整する
3. 結果を報告する：税抜・消費税・税込の増額前後、数量を変えた項目数、係数（約何倍か）、％連動項目の変更
4. 次の点を必ず伝える：
   - 数量は図面の実測値ではなくなるため、数量根拠の説明を求められると困る
   - 係数が1.2倍近くなるなど大きい場合は、産廃量（㎥）など連動すべき項目が見積上不自然にならないか
   - 見積日付・有効期限は元のまま（変更するか確認）

## 注意

- 顧客情報・金額情報を含むため、外部サービスへアップロードしない
- 元ファイルは上書きしない
