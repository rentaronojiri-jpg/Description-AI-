# 見積書作成スキル

現場の写真・動画フレームから工事内容を読み取り、見積書HTMLを自動生成するスキル。

## 使い方

```
/見積書作成
```

実行後、Claude が以下の情報を確認する。不明な項目はデフォルト値を使用する。

---

## 実行手順

### 1. 入力情報を収集する

ユーザーに以下を確認する（まとめて1回で聞く）：

- **現場写真・画像**：チャットに貼り付けてもらう（すでにある場合はスキップ）
- **顧客名**：見積書の宛名（例: 田中 太郎 様）
- **工事場所**：住所または略称（例: 練馬区関町）
- **工事名**：任意（不明なら画像から推定）
- **会社情報**：施工会社名・住所・TEL（初回のみ。2回目以降はCLAUDE.mdに追記して省略可）

### 2. 画像から工事内容を分析する

画像を読み込み、以下を判断する：

- 工事の種類（塗装・解体・防水・内装など）
- 施工箇所（外壁・屋根・床・天井など）
- 規模感（面積・数量の目安）
- 特記事項（劣化具合・危険箇所・養生の必要性など）

### 3. 単価・数量を決定する

単価・数量は次の優先順位で参照する。上位が見つからない、または情報が古い場合のみ下位に切り替える：

1. 同じ現場・類似案件の過去見積書（`★現場ごと/<案件名>/`、`予算管理/`）
2. `AI学習用/` のPDFサンプル・過去の単価レンジのメモリ

`AI学習用/` の主なサンプル：

```
AI学習用/20260514常総市ガレージお見積り.pdf
AI学習用/20260526恵比寿お見積り.pdf
AI学習用/20260601お見積り.pdf
AI学習用/練馬区関町 リノベーション工事御見積書0425.pdf
```

単価が不明な項目は「要確認」と記入し、後でユーザーが編集できるようにする。

### 4. HTMLファイルを生成する

`見積もり作成/見積書テンプレート_単価編集用.html` をベースに、以下を埋め込んだHTMLを生成する：

- 見積番号：`YYYY-MMDD-001` 形式（今日の日付）
- 見積日付・有効期限（1ヶ月後）
- 顧客名・工事名・工事場所・工期予定
- 明細行（セクション別に分類）
- 合計金額・消費税（10%）・税込総額

**出力先**：`見積もり作成/見積もり生成/output/`（該当案件があれば `★現場ごと/<案件名>/` でも可）
**ファイル名**：`見積書_<工事種別>_YYYYMMDD.html`

### 5. 金額チェックをする

`見積もり作成/見積書の金額チェック基準.md` の10項目で、生成したHTMLをチェックする。画面の金額欄はブラウザで計算されるため、数量×単価は自分で計算し直す。全部合格なら一言だけ、引っかかった行は「項目／該当の行／理由／過去の目安」の表だけを出す。見積書全体の要約は出さない。

### 6. 完成を報告する

生成したファイルのパスを伝え、以下を案内する：

- ブラウザで開いて金額・数量を直接編集できること
- 「印刷 / PDF保存」ボタンでPDF化できること
- 印刷はA4横が標準（テンプレートの `@page` で固定済み）
- 修正が必要な場合はチャットで伝えてもらえばすぐ対応できること

---

## 出力ルール

- 印刷レイアウトはA4横・余白10mmが標準。テンプレートの `@media print` / `@page` / `beforeprint` JS を崩さない（備考欄のリサイズつまみ非表示、備考欄の拡大、薄文字の黒化、空欄セルの線消し、印刷前の全テキストエリア高さ再計算を含む）
- 消費税は10%。見積書には会社名・工事名・作成日・有効期限を必ず記載する（見積書として成立しなくなるため）
- 金額はすべて円（¥）表記、カンマ区切り
- 数量の単位：面積→㎡、長さ→m、個数→式・箇所・枚
- セクション例：「仮設工事」「下地処理」「塗装工事」「付帯工事」「諸経費」
- 備考欄に特記事項・注意点を記載する

## デフォルト会社情報（変更があればCLAUDE.mdに追記する）

施工会社名・住所・TELが不明な場合は `○○` のままにして、ユーザーが後で編集する。
