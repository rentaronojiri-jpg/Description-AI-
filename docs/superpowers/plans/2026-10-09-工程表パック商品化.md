# 工程表パック 商品化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 実案件の情報を含まない「工程表パック」（編集機能つきテンプレート＋施工者向け使い方＋発注者向けチェックリスト＋ご利用上の注意）を ZIP 1つで作る。

**Architecture:** 既存の `工程表作成/工程表テンプレート_編集版.html` を商品用にコピーして会社フッターだけ差し替え、架空案件の `sample_state.json` を埋め込んで HTML を生成する。説明書3点は静的HTML（A4印刷）。全生成物を禁止語スキャン・描画・A3印刷の自動テストで検査し、最後に ZIP 化する。既存ファイルは一切変更しない。

**Tech Stack:** Python 3 標準ライブラリ（unittest）、PyMuPDF（`fitz`、PDFのページ数確認）、Chrome/Edge のヘッドレス（描画とPDF）、既存の `工程表作成/build_schedule.py`。

**Spec:** `docs/superpowers/specs/2026-10-09-工程表パック商品化-design.md`

## Global Constraints

- 作業場所は新規 `商品化/工程表パック/` のみ。`工程表作成/`・`★現場ごと/` などの既存ファイルは変更しない（読み取りのみ）。
- 実名・実データ禁止: 中目黒、AXIS、株式会社AXIS、英進、登録番号 `T7030001171938`、電話番号、郵便番号、住所、担当者名、金額。サンプルは架空案件「◯◯ビル改修工事」。
- 外部サービスにアップロードしない（CDN参照・外部フォントも使わない）。
- 法令に関する記載は「目安」「要確認」と明記し、断定しない。
- 印刷はA3横1ページ（工程表）。説明書はA4。`print-color-adjust: exact`。
- 平易な日本語（使い手は事務・現場担当）。
- 販売場所・値段・販売名義は未決。商品内に特定の会社名・屋号を入れない（工程表下部のフッターは空欄の編集欄にする）。
- 本人が中身を確認するまで、販売ページへ出さない。

## Review Focus

- 白紙版（`tasks:[]`）を開いたとき、画面が崩れず行を追加できること（空の状態で例外が出ない）。
- 着工日を休工日（日曜・祝日）に変えても、直後の稼働日に自動で寄ること（既存機能が商品用コピーでも壊れていない）。
- 保存した `.html` を再度開いても、フッター欄・サンプルの編集内容が保たれること。
- PDF が A3 横の1ページに収まり、2ページ目にはみ出さないこと。
- 生成物のどこか（HTML内のJSON、`<title>`、メタ情報、ZIPのファイル名）に実名が残っていないこと。

```python
# -*- coding: utf-8 -*-
"""src から dist を作る。  使い方: python build_pack.py"""
import json, os, pathlib, subprocess, tempfile

HERE = pathlib.Path(__file__).resolve().parent
SRC, DIST = HERE / 'src', HERE / 'dist'
CHROMES = [r'C:\Program Files\Google\Chrome\Application\chrome.exe',
           r'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe',
           r'C:\Program Files\Microsoft\Edge\Application\msedge.exe']


def find_chrome():
    for p in CHROMES:
        if os.path.exists(p):
            return p
    raise RuntimeError('Chrome/Edge が見つかりません')


def make_html(state_file, title):
    html = (SRC / 'template.html').read_text(encoding='utf-8')
    st = json.loads((SRC / state_file).read_text(encoding='utf-8'))
    return html.replace('{{TITLE}}', title).replace('/*STATE*/{}', json.dumps(st, ensure_ascii=False).replace('<', '\\u003c'))


def _run_chrome(args):
    with tempfile.TemporaryDirectory() as prof:
        return subprocess.run([find_chrome(), '--headless=new', '--disable-gpu', f'--user-data-dir={prof}', *args],
                              capture_output=True, timeout=120)


def render_dom(html_path):
    r = _run_chrome(['--dump-dom', pathlib.Path(html_path).resolve().as_uri()])
    return r.stdout.decode('utf-8', 'replace')


def make_pdf(html_path, pdf_path):
    _run_chrome(['--no-pdf-header-footer', f'--print-to-pdf={pathlib.Path(pdf_path).resolve()}',
                 pathlib.Path(html_path).resolve().as_uri()])
    return pathlib.Path(pdf_path).exists()


def build(dest):
    dest = pathlib.Path(dest)
    dest.mkdir(exist_ok=True)
    out = {}
    sample = dest / '工程表テンプレート_サンプル入り.html'
    sample.write_text(make_html('sample_state.json', '工程表 - サンプル'), encoding='utf-8')
    blank = dest / '工程表テンプレート_白紙.html'
    blank.write_text(make_html('blank_state.json', '工程表'), encoding='utf-8')
    pdf = dest / '工程表サンプル.pdf'
    make_pdf(sample, pdf)
    out.update(sample=sample.name, blank=blank.name, pdf=pdf.name)
    return out


if __name__ == '__main__':
    print(build(DIST))
```

def make_zip(dest):
    import zipfile
    dest = pathlib.Path(dest)
    z = dest / '工程表パック.zip'
    with zipfile.ZipFile(z, 'w', zipfile.ZIP_DEFLATED) as zf:
        for p in sorted(dest.iterdir()):
            if p.name != z.name:
                zf.write(p, p.name)
    return z


if __name__ == '__main__':
    print(build(DIST))
    print(make_zip(DIST))
