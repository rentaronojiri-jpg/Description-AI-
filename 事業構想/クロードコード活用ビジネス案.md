# クロードコードを使ったビジネス案

作成日: 2026-08-30
前提: 本リポジトリ（AI事務）で稼働中の資産をそのまま商材化する前提で検討。

---

## 0. 手元にある「資産」の棚卸し

| 資産 | 中身 | 商材としての価値 |
|---|---|---|
| `/見積書作成` スキル | 現場写真・動画から工事内容を読み取り見積書HTMLを生成 | **最重要**。他社が真似しにくいのは「実勢単価の勘所」の部分 |
| `AI学習用/` の実見積PDF 4件 | 常総市ガレージ・恵比寿・練馬区関町ほか | 実勢価格の学習データ。競合が持っていない |
| `/業者一覧作成` `/予算管理PDF読み込み` | 業者見積PDF群 → 一覧表・予算表へ自動転記 | 事務代行サービスの中核 |
| `/書類チェック` | 契約書・請求書の記入漏れ・不備チェック | 単体でも売れる（トラブル予防） |
| `見積書テンプレート_単価編集用.html` | ブラウザ上で単価を編集できるHTML | 顧客に納品しても使える完成品 |
| `工程表作成` | 工程表HTML生成 | 提案書とセットで付加価値 |
| `施工管理アプリ`（React/Vite PWA） | タスク管理・ガント | SaaS化の種 |
| `.claude/commands/` 6本 + `CLAUDE.md` | 業務手順が言語化済み | **そのまま「導入パッケージ」として売れる** |

ポイント: すでに「業務手順がテキストで言語化されている」こと自体が商品。
建設業の事務は属人化していて、ここを言語化できている会社はほぼない。

## 1. 事業案（推奨順）

### 案A: 見積書作成の受託代行（BPO） ★最速で現金化

**内容**: 工務店・リフォーム会社から現場写真/動画をLINEやメールで受け取り、
見積書HTML/PDFを納品する。中身は `/見積書作成` スキルを回すだけ。

- 価格: 1件 5,000〜15,000円（工事規模による）／月額プラン 月10件 8万円〜
- 原価: Claude利用料 + 自分の確認時間30分程度
- 立ち上げ: 今日からできる。営業先は既に付き合いのある工務店・業者
- 刺さる理由: 中小工務店の社長は「見積作成に丸一日潰れる」のが最大の不満。
  相見積もりのスピードが受注率に直結する

**リスク**: 金額を間違えると信用問題。→ 必ず人間の最終確認を挟み、
「AI一次案 + 人間チェック済み」を明示する。責任範囲を契約書に書く。

---

### 案B: 建設会社向け「AI事務」導入パッケージ販売 ★利益率が最も高い

**内容**: 本リポジトリの `CLAUDE.md` + `.claude/commands/` 一式を、
顧客企業の業務に合わせてカスタマイズして納品 + 使い方研修。

- 価格: 初期導入 30〜80万円 ／ 保守・スキル追加 月3〜5万円
- 納品物:
  1. その会社専用の `CLAUDE.md`（会社情報・単価表・書式ルール）
  2. カスタムスキル 5〜8本（見積・業者管理・予算・書類チェック等）
  3. 操作マニュアル（動画付き）
  4. 3ヶ月の伴走サポート
- 強み: 「うちも同じ工事業なので、業界の言葉が通じる」が最大の差別化。
  ITコンサルには絶対に書けない `CLAUDE.md` が書ける

**最大の障壁**: Claude Code はCLIツール。現場の事務員さんには敷居が高い。
→ 対策として、よく使う操作だけボタン化した簡易ランチャー（.bat / 簡易Web UI）を
同梱する。これが実質の参入障壁になる。

---

### 案C: 「動画で見積もり」サービスのプロダクト化

**内容**: 案Aを仕組み化。施主または元請けが現場動画をアップ →
数時間で概算見積が返る、というWebサービス。

- 価格: 概算見積 無料 or 3,000円 → 本見積・施工は提携工務店へ送客（送客手数料）
- 収益モデル: **見積そのものではなく「送客」で稼ぐ**のが本命
- 技術: 施工管理アプリ（React/Vite）を土台に、Claude API を裏で叩く構成
- 期間: 3〜6ヶ月

**注意**: これは案A・案Bで実績と単価データを貯めてから着手すべき。
いきなりやるとデータがなく精度が出ない。

---

### 案D: 書類チェック単体サービス

**内容**: `/書類チェック` を独立商材化。契約書・業者見積・請求書を投げると
記入漏れ・単価の異常値・条件の不利な箇所をレポート。

- 価格: 1件 3,000円 ／ 月額 2万円で見放題
- 強み: 単価が安く導入しやすい → 案A・案Bへのフロントエンド商品として最適
- 拡張: 「相見積もりの妥当性診断」（複数業者の見積を比較し高い項目を指摘）は
  施主側にも売れる

---

### 案E: 情報発信・コンテンツ販売

**内容**: 「建設業の事務をClaude Codeで自動化した記録」をnote/YouTube/Xで発信。
スキルパック（CLAUDE.md + commands のテンプレ）をダウンロード販売。

- 価格: スキルパック 9,800〜29,800円
- 役割: 単体では大きく稼げないが、**案A・案Bの見込み客を集める装置**として機能
- コスト: ほぼゼロ。実務の副産物をそのまま出せる

## 4. リスクと対策

| リスク | 対策 |
|---|---|
| 見積金額のミス → 損害賠償 | 「AI一次案・最終判断は発注者」と契約書に明記。必ず人間が最終確認 |
| 顧客情報・金額の外部流出 | `CLAUDE.md` の方針どおり、外部サービスへのアップロードは行わない。ローカル処理を売り文句にする |
| 建設業のITリテラシー | CLIを触らせない。ボタン/LINE/メールで完結する導線を必ず用意する |
| AIツールの陳腐化・競合参入 | 真似できないのは「実勢単価データ」と「業界の言語化」。ツールではなくデータと業務知識を資産化する |
| 自分の時間が足りない | 案Aを受けすぎない。20件/月を超えたら値上げか案Bへ移行 |

## 5. 差別化の核（ここだけは外さない）

競合になるのは「AIコンサル」だが、彼らには以下が無い:

1. **実勢単価の相場観** — 実際の見積PDFから学習した数字
2. **建設業の業務フローの言語化** — 何を確認し、何を落とすとトラブルになるか
3. **現場の言葉** — 工種名・職人さんとのやりとり・元請け下請けの商習慣

売っているのは「AI」ではなく「建設事務の型」。AIはその配達手段にすぎない。
