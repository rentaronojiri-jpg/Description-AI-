# 株予測ツール

株式会社AXISの建設事務とは無関係の、個人用の株価予測ツール。ここは独立したプロジェクトとして扱う。

## 概要

- Web版（`webapp/`）は常時オンライン専用。yfinanceからのライブ取得のみで、キャッシュは持たない
- テクニカル・ファンダメンタルズ・世界情勢の3専門エージェントによるチーム評価で銘柄を分析する
- 起動は `/株予測ツール起動` スキルを使う（詳細な起動手順はそちらに記載、ここには重複記載しない）

## 構成

| ファイル/フォルダ | 内容 |
|----------|------|
| `stock_predictor.py` | 予測ロジック本体 |
| `analysis_core.py` | 分析コア処理 |
| `webapp/` | Flask製Web版（`server.py`、`static/`） |
| `output/` | 生成した分析結果HTML |

## 注意事項

- ポート8765を使用。既に起動中なら再起動せず、ブラウザで開き直すだけでよい
- Bashツールでこのフォルダのパスを扱う際は forward slash（`webapp/server.py`）を使う。backslashだとエスケープが壊れる
