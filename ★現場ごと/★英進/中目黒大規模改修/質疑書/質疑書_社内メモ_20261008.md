## 4. 質疑書に入れなかった法令担当のNo.7

法令担当の質疑案 No.7（元請の英進様が持つ建設業許可・解体工事業の登録区分、契約書の取り交わし時期、再下請の承認）は、質疑書に入れませんでした。理由は、元請の許可区分や当社との契約形態に踏み込む内容で、質疑書（現場の条件確認）ではなく、営業・契約の話として直接確認するほうが自然だからです。

- 契約書の取り交わし時期は、質疑 No.55（着工までに完了が必要な事項）の中に「契約締結」として含めてあります。
- 当社の解体工事業の登録番号・許可の確認書類を求められた場合の提出準備は、社内で進めておくと安心です。

## 5. 質疑書に入れなかったその他の事項

- 見積有効期限が2026年10月23日で、着工予定（11月16日）より前に切れる点。見積の出し直しか、期限の延長が必要です。見積の「工期予定」欄も空欄です。
- 数量の食い違い（質疑書では範囲・数量の確認の形でのみ聞いています）
  - EV開口の寸法：0917版は約1.775×2.2m（約3.9㎡）、最新見積は4.5㎡。カッター長7.95mは1.775×2.2mの周りの長さと一致しており、旧寸法のまま計算している可能性があります。
  - EV開口の足場は4式、見積内訳の表題は5区間（B1、B1〜1F、1F〜2F、2F〜3F、3F〜RF）で、数が合っていません。質疑書では、貫通スラブを1F・2F・3F・RFの4か所とB1ピット（別項目）に分けて聞いています（質疑 No.35、39）。
  - 既存アスファルト：見積は101㎡、工程表の注記は約85㎡です。
  - 外部足場：0924版は1,588.9㎡、最新見積は2,218㎡（約40%増）で、算定図が必要です。
- 工程が詰まっている箇所：1階RCはつり221㎡を6日、B1のRCはつり103㎡を3日で見込んでいます。騒音の制限や構造協議が長引くと延びます。1月に階段・EV開口・シャッター撤去が集中しています。
- 他社宛の見積（クリエート・スペース宛 94,600円）は本件と無関係なので、質疑書には一切使っていません。
- 質疑書には、金額、自社の弱みになる内容、写真から読み取った距離の数値（レーザー測定値など）は書いていません。
- 石綿は「含有している」とは書かず、調査結果の有無・提示を求める形にしています。
- 室名・階は、写真から推定したものを「(推定)」と付けています。図面で室名を確認できたら、書き直してください。

## 8. 法令の再確認先（質疑書提出前・後に確認）

質疑書では、条文番号は確実なものだけにしています（廃棄物処理法第21条の3、道路交通法第77条、道路法第32条、労働安全衛生法第88条）。石綿・フロンなど、改正が続いている分野は「最新の運用を確認のうえご教示」の形にしています。

| 内容 | 確認先 |
|---|---|
| 石綿の事前調査の資格者要件、結果の電子報告の報告義務者・名義 | 厚生労働省・環境省の最新の案内、目黒区・東京都の窓口 |
| 石綿除去の届出（作業開始14日前など）の届出者 | 所轄の労働基準監督署、東京都・目黒区の窓口 |
| フロン類の回収・書面確認の細目 | 環境省・経済産業省の最新の案内、東京都の窓口 |
| 建設リサイクル法の対象規模の判定、届出先・様式 | 目黒区の窓口（建築・環境担当） |
| 騒音・振動の特定建設作業の届出、作業時間の制限 | 目黒区の環境担当窓口 |
| 道路使用許可・道路占用許可 | 所轄警察署（道路使用）、道路管理者（占用） |
| 消防用設備の停止・着工届、危険物（灯油ボイラー）の廃止届、工事中の消防計画 | 所轄の消防署 |
| 足場の計画届、作業主任者の選任 | 所轄の労働基準監督署 |
| 建築確認申請の要否（EV新設・主要構造部の一部撤去） | 目黒区の建築指導担当、設計者様 |

延床面積（解体部分の床面積）がまだ不明なため、建設リサイクル法の対象規模や、足場計画届の要否の判定は、建築概要が届いてからになります。
